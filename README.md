# Advent of Code

Solutions organized by year.

## Structure

- `2024/` — LINQPad solutions for Advent of Code 2024 (days 1–24)
- `AoC2025/` — C# solutions for Advent of Code 2025 (C# project, run via `Framework/`)

## Running 2025 Solutions

Open `AdventOfCode.slnx` in Visual Studio or Rider and run the `Framework` project.

## Running 2024 Solutions

Open the `.linq` files in [LINQPad](https://www.linqpad.net/). Each puzzle's solution is self-contained in its day folder under `2024/`.
